Para rodar o arquivo existem 2 maneiras:

1ª: Através dos executáveis

Localize na pasta /dist os executáveis server_gui.exe (execute-o primeiro) e posteriormente execute game_client.exe

2ª: Digite no terminal os seguintes comandos (terminais distintos):

py server.py

py game_client.py

OBS: Caso não tenha o pygame instalado nessa segunda opção, instale-o no terminal digitando  " pip install pygame "
