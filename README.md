Para rodar o arquivo existem 2 maneiras:

1ª:  Digite no terminal (do VScode) os seguintes comandos (cada comando precisa ser digitado em terminais distintos):

py server.py

py game_client.py

OBS: Caso não tenha o pygame instalado, instale-o no terminal digitando  " pip install pygame " para rodar o arquivo corretamente.

2ª: Através dos executáveis

Localize na pasta /dist os executáveis server_gui.exe (execute-o primeiro) e posteriormente execute game_client.exe
